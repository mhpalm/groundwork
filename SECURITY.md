# Security

Please report security issues privately, not in a public issue. Use GitHub's private vulnerability reporting on this repository ("Report a vulnerability" under the Security tab).

Groundwork is especially interested in:

- Prompt injection: text read from an org's systems or tracker that changes what Groundwork plans or writes.
- Data leaks: record-level personal or financial data, credentials, or restricted configuration appearing in evidence, proposals, snapshots or tracker items.
- Approval bypass: any way to create tracker items without an authenticated approval that matches the plan's hashes.
- Cross-org mixing: any way for one run to read or write another organization's systems.

Include the skill versions (from the plan's stamps footer), the surface, and the smallest steps that reproduce it.
